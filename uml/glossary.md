Дата: 2026-11-17

| Термин | Определение |
|--------|-------------|
| TypePulse | Веб-приложение — интерактивный тренажёр скорости печати |
| Пользователь (User) | Зарегистрированная учётная запись с доступом к тренировкам, истории и рейтингу |
| Гость (Guest) | Неавторизованный посетитель, видит только лендинг и формы входа/регистрации |
| Актёр | Роль внешнего участника относительно системы (человек или внешняя сущность) |
| Прецедент (Use Case) | Последовательность действий системы в ответ на инициирующее событие актёра |
| Поток событий | Пошаговое описание основного, альтернативных и ошибочных сценариев прецедента |
| Предусловие | Условие, которое должно выполняться до старта прецедента |
| Постусловие | Условие, которое должно выполняться после завершения прецедента |
| Тренировка / сеанс | Сеанс набора эталонного текста с таймером и измерением метрик |
| Эталонный текст | Текст, который пользователь должен набрать (TextSnippet) |
| WPM | Words Per Minute — скорость: `(correctChars / 5) / (elapsedMs / 60000)` |
| Точность (Accuracy) | `(correctChars / max(typedChars, 1)) * 100%` |
| Ошибка ввода | Символ, введённый пользователем и не совпавший с эталоном в текущей позиции |
| Подсветка | Визуальная индикация верных и неверных символов на экране тренировки |
| Результат (Result) | Сохранённые метрики завершённого сеанса (WPM, точность, ошибки, время) |
| История | Список результатов текущего пользователя (новые сверху, до 50+) |
| Рейтинг (Leaderboard) | Топ-20 пользователей по лучшему WPM (при равенстве — по точности) |
| Настройка тренировки | Выбор языка (RU/EN), длительности (30/60/120 с) и сложности |
| Пользовательский текст | Текст, загруженный самим пользователем для тренировки (SYS-F-08) |
| Состояние сеанса | CREATED → RUNNING → FINISHED \| CANCELLED |
| Модульный монолит | Архитектурный стиль: один deployable JAR со слоями Controller → Service → Repository |
| ADR | Architecture Decision Record — запись архитектурного решения |
| SDD | Software Design Description — описание дизайна ПО |
| SRS | Software Requirements Specification — спецификация требований |
| PlantUML | Текстовый язык и инструмент генерации UML-диаграмм |
