## Актёры

### Гость
Неавторизованный посетитель сайта. Может просматривать главную страницу и выполнять регистрацию или вход.

### Пользователь
Авторизованная учётная запись. Проводит тренировки, сохраняет результаты, просматривает историю и рейтинг, загружает свои тексты.

### Таймер (время)
Внешний «актёр-время»: по истечении выбранной длительности инициирует завершение сеанса тренировки.

## UC-01. Зарегистрироваться

**Пояснение:** Создать новую учётную запись (логин, email, пароль) для доступа к тренировкам и истории.

**Предусловия:** Пользователь не авторизован; открыта форма регистрации.

**Основной поток:**
1. Гость открывает страницу регистрации.
2. Система отображает форму (логин, email, пароль).
3. Гость вводит данные и подтверждает.
4. Система проверяет уникальность email и валидность полей.
5. Система сохраняет учётную запись с хешем пароля.
6. Система сообщает об успехе и предлагает войти (или выполняет автоматический вход).

**Альтернативный поток A1 (email занят):** на шаге 4 система отклоняет регистрацию с понятным сообщением; прецедент завершается без создания учётки.

**Поток ошибки E1:** сбой сохранения — система показывает сообщение об ошибке, учётка не создаётся.

**Постусловия:** Существует новая учётная запись с хешированным паролем (или состояние без изменений при отказе).

**Трассировка:** REQ-FUNC-001, SYS-F-01, REQ-SEC-001.

---

## UC-02. Войти в систему

**Пояснение:** Аутентификация по логину/email и паролю с созданием сессии.

**Предусловия:** Учётная запись существует; пользователь не авторизован (или сессия истекла).

**Основной поток:**
1. Гость открывает страницу входа.
2. Вводит учётные данные и подтверждает.
3. Система проверяет хеш пароля.
4. Система создаёт сессию и перенаправляет на главную / настройку тренировки.

**Альтернативный поток A1:** неверные данные — сообщение об ошибке, сессия не создаётся.

**Постусловия:** Активная сессия Пользователя.

**Трассировка:** REQ-FUNC-001, SYS-F-01.

---

## UC-03. Выйти из системы

**Пояснение:** Завершение сессии авторизованного пользователя.

**Предусловия:** Пользователь авторизован.

**Основной поток:**
1. Пользователь выбирает «Выход».
2. Система инвалидирует сессию.
3. Система показывает главную страницу для Гостя.

**Постусловия:** Сессия отсутствует; доступны только публичные экраны.

---

## UC-04. Настроить тренировку

**Пояснение:** Выбор языка (RU/EN), длительности (30/60/120 с) и сложности (лёгкий/средний/сложный); опционально — пользовательский текст.

**Предусловия:** Пользователь авторизован.

**Основной поток:**
1. Пользователь открывает экран настройки.
2. Выбирает параметры (и при необходимости свой текст).
3. Система валидирует выбор и сохраняет параметры для старта сеанса.
4. Пользователь переходит к старту тренировки.

**Постусловия:** Параметры тренировки зафиксированы для следующего сеанса.

**Трассировка:** REQ-FUNC-002, SYS-F-04, SYS-F-08.

---

## UC-05. Провести тренировку

**Пояснение:** Отображение эталонного текста, посимвольный ввод с подсветкой, обратный отсчёт, завершение по таймеру или концу текста.

**Предусловия:** Пользователь авторизован; параметры тренировки заданы (UC-04); выполнен вход (include UC-02 при необходимости).

**Основной поток:**
1. Пользователь нажимает «Старт».
2. Система создаёт сеанс со статусом RUNNING, выдаёт текст, ставит фокус на поле ввода.
3. Пользователь вводит символы; система подсвечивает верные/неверные и обновляет live-WPM.
4. По истечении времени (актёр «Таймер») или исчерпании текста система вызывает завершение (UC-06).

**Альтернативный поток A1 (обрыв сети):** сеанс → CANCELLED; успешный результат не сохраняется; пользователю показывается сообщение (REQ-REL-001).

**Постусловия:** Сеанс в состоянии FINISHED или CANCELLED.

**Трассировка:** REQ-FUNC-003, REQ-INT-002, SYS-F-02, SYS-NF-01.

---

## UC-06. Рассчитать и сохранить результат

**Пояснение:** Серверный расчёт WPM, точности, числа ошибок и сохранение Result.

**Предусловия:** Существует сеанс в состоянии RUNNING (или корректно завершаемый).

**Основной поток:**
1. Клиент отправляет финальный ввод / сигнал finish.
2. Система рассчитывает метрики по формуле VIEW-006 / REQ-FUNC-004.
3. Система переводит сеанс в FINISHED и сохраняет неизменяемый Result.
4. Система показывает экран результата.

**Альтернативный поток A1:** сеанс уже CANCELLED / FINISHED — повторная запись не создаётся (идемпотентность по sessionId).

**Постусловия:** Result сохранён и доступен в истории; сеанс FINISHED.

**Трассировка:** REQ-FUNC-004, REQ-FUNC-005, SYS-F-03, SYS-F-05.

---

## UC-07. Просмотреть историю

**Пояснение:** Список собственных результатов (не менее последних 50), новые сверху.

**Предусловия:** Пользователь авторизован.

**Основной поток:**
1. Пользователь открывает «История».
2. Система загружает результаты текущего userId.
3. Система отображает таблицу (дата, WPM, точность, язык, длительность, сложность).

**Постусловия:** Пользователь видит только свои данные.

**Трассировка:** REQ-FUNC-006, REQ-SEC-002, SYS-F-06.

---

## UC-08. Просмотреть рейтинг

**Пояснение:** Таблица лидеров топ-20 по лучшему WPM (при равенстве — по точности).

**Предусловия:** Пользователь авторизован (в MVP рейтинг доступен после входа).

**Основной поток:**
1. Пользователь открывает «Рейтинг».
2. Система агрегирует лучшие WPM.
3. Система отображает топ-20 (ник, WPM, точность).

**Постусловия:** Показаны публичные данные рейтинга без чужой детальной истории.

**Трассировка:** REQ-FUNC-007, SYS-F-07.

---

## UC-09. Загрузить пользовательский текст

**Пояснение:** Добавление собственного plain-text фрагмента (≤ 2000 символов) для тренировки.

**Предусловия:** Пользователь авторизован.

**Основной поток:**
1. Пользователь открывает форму пользовательских текстов.
2. Вводит/вставляет текст и подтверждает.
3. Система валидирует длину и сохраняет TextSnippet с ownerUserId.
4. Текст становится доступен в настройке тренировки.

**Альтернативный поток A1:** длина > 2000 или пустой текст — отказ с сообщением.

**Постусловия:** Новый TextSnippet принадлежит пользователю.

**Трассировка:** SYS-F-08.
