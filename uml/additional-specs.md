# Дополнительные спецификации TypePulse

Версия 0.1  
Лабораторная работа №5  
Подготовила: Лубочко Ульяна Антоновна, группа 450501  
Дата: 2026-11-17

Документ фиксирует нефункциональные и сквозные ограничения, дополняющие SRS и описания прецедентов.

## 1. Платформа и окружение

| ID | Спецификация |
|----|--------------|
| AS-01 | Серверная часть — Java 17+, Spring Boot (модульный монолит, ADR-001) |
| AS-02 | Клиент — актуальные Chrome / Firefox / Edge (последние 2 major-версии) |
| AS-03 | Локальный профиль использует H2; учебный/демо — PostgreSQL по возможности |
| AS-04 | Запуск по инструкции README одной командой (REQ-INST-001) |

## 2. Безопасность и данные

| ID | Спецификация |
|----|--------------|
| AS-05 | Пароли хранятся только как криптографический хеш (BCrypt), не в открытом виде |
| AS-06 | Пользователь видит только свою историю; в рейтинге публичны ник и лучший WPM |
| AS-07 | Собираются только: логин, email, хеш пароля, параметры и результаты тренировок |
| AS-08 | Журнал ERROR без паролей и токенов в открытом виде |

## 3. Производительность и надёжность

| ID | Спецификация |
|----|--------------|
| AS-09 | Подсветка символа на экране тренировки ≤ 100 мс локально (REQ-PERF-001) |
| AS-10 | Финальные метрики рассчитываются на сервере (источник истины) |
| AS-11 | При обрыве сети сеанс переводится в CANCELLED; успешный Result не создаётся |
| AS-12 | Страницы истории/рейтинга ≤ 2 с при объёме до 10 000 результатов (учебная среда) |

## 4. Правила предметной области

| ID | Спецификация |
|----|--------------|
| AS-13 | WPM = (correctChars / 5) / (elapsedMs / 60000); точность = (correctChars / max(typedChars, 1)) × 100 |
| AS-14 | Длительности сеанса: 30 / 60 / 120 секунд; языки: RU / EN; сложность: лёгкий / средний / сложный |
| AS-15 | Пользовательский текст: plain text, длина ≤ 2000 символов |
| AS-16 | Рейтинг: топ-20 по лучшему WPM, при равенстве — по точности |
